OPIK AI 2.0

Что внутри:
- index.html — готовый мобильный интерфейс Opik AI.
- 4 режима: Чат, Код, Объяснить, Ошибка.
- Настройки для адреса API-сервера.
- Место для подключения настоящей ИИ-модели.

Как запустить:
1. Распакуй ZIP.
2. Открой index.html в браузере.
3. Для настоящего ИИ нужен API-сервер.

Формат запроса к API:
POST <apiUrl>
Content-Type: application/json

{
  "message": "текст пользователя",
  "mode": "chat"
}

Ожидаемый ответ:
{
  "reply": "ответ ИИ"
}

ВАЖНО:
Не помещай секретный API-ключ непосредственно в index.html. Храни его на сервере и вызывай модель через свой backend.
